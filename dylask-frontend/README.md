# Dylask Frontend

Giao diện Single Page Application xây dựng bằng **React 19**, **TypeScript**, và **Vite**.

---

## 🛠️ Công nghệ sử dụng
- **Framework:** React 19 + React Compiler
- **Bundler:** Vite 8
- **Ngôn ngữ:** TypeScript
- **Linter:** ESLint 10

---

## 🚀 Khởi chạy

```bash
# Cài đặt thư viện
npm install

# Khởi chạy dev server (http://localhost:5173)
npm run dev

# Kiểm tra lỗi linter
npm run lint

# Build cho môi trường production
npm run build
```

---

## 🌐 Biến môi trường
Xem file `.env.example`:
```env
VITE_API_BASE_URL=http://localhost:8080/api/v1
```
