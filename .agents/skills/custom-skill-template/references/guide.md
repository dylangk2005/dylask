# Tài Liệu Tham Khảo Kỹ Thuật (Technical Reference)

Tài liệu này cung cấp ngữ cảnh chi tiết, quy chuẩn hoặc danh sách API được tách riêng ra khỏi `SKILL.md` nhằm tối ưu context window cho AI (theo cơ chế Progressive Disclosure).

## 1. Thông số kỹ thuật / Quy chuẩn
- Liệt kê các quy định, cấu hình hoặc format dữ liệu liên quan ở đây.

## 2. Đường dẫn tài liệu mở rộng
- Khi AI cần đọc thêm chi tiết, AI sẽ truy cập file này qua relative link từ `SKILL.md`.
