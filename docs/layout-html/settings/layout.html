Hạn mức miễn phí

Sử dụng hạn ngạch Gemini Flash mặc định của hệ thống. Phù hợp cho nhu cầu cơ bản hàng ngày.

Khóa riêng (BYOK)

Tự cung cấp Google Gemini API Key. Tốc độ cao, không phụ thuộc hạn mức dùng chung.

Google Gemini API Key

Nhập khóa API nhận từ Google AI Studio để kết nối trực tiếp.

* Khóa API chỉ được mã hóa và lưu trữ riêng cho tài khoản này trên cơ sở dữ liệu của bạn, không chia sẻ với bên thứ ba.

Chế độ giao diện mặc định

Chọn chế độ tự động áp dụng mỗi khi bạn đăng nhập vào Dylask.

Standard Mode

Giao diện sáng, thoáng đãng, thân thiện. Tập trung vào quản lý công việc cá nhân, gia đình và thói quen hàng ngày.

Developer Mode

Giao diện tối, mật độ thông tin cao. Tối ưu cho quản lý sprint, Kanban board, Markdown và tự động hóa Git.

Thông báo nổi trên trình duyệt

Hiển thị cảnh báo trực tiếp trên màn hình khi công việc sắp đến hạn hoặc phiên Pomodoro kết thúc.

Email nhắc việc định kỳ

Gửi email tóm tắt công việc tồn đọng và thông báo việc quá hạn đầu ngày.
