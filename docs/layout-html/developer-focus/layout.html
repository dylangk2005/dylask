Xây dựng lớp lọc JwtAuthenticationFilter kế thừa từ OncePerRequestFilter. Trích xuất chuỗi JWT từ header Authorization: Bearer <token>, xác thực chữ ký HMAC-SHA256 với secret key trong biến môi trường và nạp quyền vào SecurityContextHolder.

  "status": "success",
  "data": {
    "tokenType": "Bearer",

    "refreshToken": "d8f2a1b9-3c4e-4f7a-8b...",
    "expiresIn": 900
  }
}
