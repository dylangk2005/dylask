Yêu cầu kiến trúc Spring Security

Cần triển khai Filter kế thừa OncePerRequestFilter để chặn mọi request tới /api/v1/** ngoại trừ endpoint /auth/**.

  • Cấu hình thuật toán HMAC-SHA256 với secret key từ env
  • Parse JWT claims và inject vào SecurityContextHolder
  • Xử lý bắt ngoại lệ ExpiredJwtException qua AuthenticationEntryPoint
JwtAuthenticationFilter.java Java 25 
public class JwtAuthenticationFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(HttpServletRequest req,
                                    HttpServletResponse res,
                                    FilterChain chain) {
        String auth = req.getHeader("Authorization");
        if (auth != null && auth.startsWith("Bearer ")) {
            String token = auth.substring(7);
            // Validate and extract claims
            Claims claims = jwtService.extractAll(token);
        }
        chain.doFilter(req, res);
    }
}
